# CS2 Discord Rich Presence

A Node.js application that displays your Counter-Strike 2 game status in Discord using Rich Presence.
Made by Jeverly (recht)

## Features

- Real-time game state integration with Discord
- Displays current map with appropriate map image
- Shows player stats (kills, deaths, assists)
- Indicates match score and game phase
- Team-specific icons
- Player name display

## Requirements

- Node.js (v16 or higher)
- Counter-Strike 2
- Discord desktop application
